## 0. 实测基线（2026-08-04，修复 verifyLoop 求逆后）

| 运行 | 有效帧 | 路径(m) | ATE RMSE(m) | 相对误差 | 备注 |
|------|--------|---------|-------------|----------|------|
| run_vo（回环关） | 4503/4541 | 3679 (GT 3680) | 178.6 | 4.80% | 绝对尺度正确 |
| run_slam（回环开） | 4541/4541 | 3718 (GT 3724) | 177.8 | 4.77% | 3 次闭环，末帧误差 150→124m |

**误差结构**：逐帧 ATE 曲线显示前 1/3 段均差 ≈69m，中段（1/3–2/3）≈185m，末端回环拉回至 ≈124m。
→ **中段旋转漂移是误差主项**；回环校正收益受限于两点：① 起点-末端真回环到 kf#4517（序列最末）才闭合，
   漂移在全程几乎无校正；② 全局 BA 为 motion-only（地图点固定），无法真正消除点-位姿残差。

**已知遗留问题**：run_slam 首跑在帧 4286 有一次非确定性静默崩溃，二跑完整通过（并行 ORB 压力测试 3×2 万次无异常）——
  疑为堆损坏或并发竞态，需 ASan 定位（P1.1）。

## 1. P0 — 回环校正链路增强（直接压 ATE）

### P0.1 全局/局部 BA 放开地图点自由度（双目全 BA）

- **问题**：`Optimizer::localBundleAdjustment` 对全部点顶点 `setFixed(true)`（motion-only）。
  回环后位姿被位姿图移动，但点坐标只按参考关键帧的位姿增量粗同步，未被重投影残差精修；
  实测回环对中段误差几乎无改善（seg2 181.6m）。
- **根因**：单目下点+位姿同时缩放存在尺度 gauge（重投影不变），点固定是当时的保守选择；
  双目有绝对尺度（视差直接测深），**尺度可观测**，点自由优化不会退化。
- **设计**：
  - `Optimizer::localBundleAdjustment` 增加参数 `bool fix_points`（默认按 `camera->hasPerFrameDepth()` 自动选择）；
  - 双目路径：点顶点**不固定**，保留最早 2 帧固定（防绝对位置/朝向 gauge）+ Huber 核 + 观测数 ≥3 过滤；
  - 单目路径：维持现状（点固定）；
  - 全局 BA 复用同一开关，回环后全图精修。
- **预期收益**：回环后中段残差真正收敛，ATE 目标 ≤ 120m（与早期单目基准同量级）。
- **风险**：BA 规模大（全图 50 万点、3133 KF）→ 计算时间上升；先验证窗口内全 BA 的耗时增幅，超预算则 P2.1 后台线程承接。
- **验证**：合成回环测试断言"回环后共视点重投影 RMSE 下降"；KITTI 00 分段 ATE 对比。

### P0.2 回环检测提前 + 参数细化

- **问题**：KITTI 00 全程仅 3 次闭环，起点-末端真回环在**最后一帧**（kf#4517）才闭合，
  全程漂移（尤其车辆掉头区域）得不到及时校正。
- **根因**：`detectLoop` 只取 DBoW3 Top-5 且 `min_score=0.1`；`loop_cooldown_frames=200`（帧）
  使同区域校正间隔过大；无位置先验（轨迹自交区域没有优先召回）。
- **设计**：
  - 候选扩 Top-5 → Top-20，时间窗过滤后按分数取最高；
  - **位置先验加速**：当新 KF 与历史 KF 的世界系距离 < 阈值（如 25m）且时间间隔足够时，
    自动把该帧设为候选（先验来自估计轨迹，无需额外传感器）；
  - 冷却改**关键帧计数**而非帧计数（当前 200 帧 ≈ 20 KF，若 KF 密度波动则冷却时间漂移）；
  - 校验 `detection_interval` 与 KF 密度解耦：改为每插入 KF 都检测，靠 min_score + 几何验证把关。
- **预期收益**：中段即可触发 2-3 次闭环，位姿图提前拉回漂移 → seg2 误差显著下降。
- **风险**：误检率上升 → 依赖 PnP 验证（min_loop_inliers=50, ratio=0.85）与时间窗双重把关；
  位置先验需要距离阈值标定。
- **验证**：KITTI 00 闭环次数 ≥6；闭环事件发生的 KF 区间前移；分段 ATE。

## 2. P1 — 前端跟踪质量与确定性

### P1.1 并行分带 ORB 确定性（ASan 定位 + 参数收敛）

- **问题**：run_slam 一次非确定性崩溃（帧 4286 静默退出，复跑通过）。
- **排查现状**：并行 ORB 提取（eebda67）为最可疑的并发点，但单进程压力测试 3×2 万次提取无异常；
  Viewer headless 不起线程；g2o 无 OpenMP。
- **设计**：
  1. **ASan/UBSan 构建**（`-fsanitize=address,undefined`）全量跑 KITTI 00，若复现直接定位；
     本机内存充足时单进程 ASan 可行（首跑 OOM 是双进程叠加导致，非单进程上限）；
  2. 分带参数收敛：`nbands` 由 `getNumThreads()` 动态推导改为固定上限（如 4），
     消除 TBB 嵌套并行度波动；`kBorder` 18→24 减少边界特征损失；
  3. 若确认竞态 → 回退单带提取（保性能用 OpenCV TBB 内置并行，dev log §3.9 已实测 11ms→4.2ms，
     单带仍远快于旧实现）。
- **预期收益**：消除崩溃不确定性（这是"流畅程度"的硬伤）。
- **验证**：连续 3 次全序列运行无崩溃；单测确定性（同帧两次提取特征一致）。

### P1.2 前端旋转漂移抑制 + RPE 指标

- **问题**：绝对尺度正确但旋转漂移主导（相对误差 4.77%），逐帧误差中段最高。
- **设计**：
  - `scripts/plot_traj.py` / `evaluate_ate.py` 增加 **RPE**（相对位姿误差，平移/旋转分开），
    量化"旋转漂移 vs 平移漂移"占比，为后续优化提供度量；
  - **深度-信息权重**：双目视差测深误差随深度²放大，PnP/BA 中按深度给观测加权
    （近点高权重），抑制远点错误点对位姿的污染；
  - 双目 Local BA 放开点自由度（与 P0.1 同开关，先在前端窗口试运行）；
  - KF 平移阈值 0.9m→0.7m 实验（更多 KF → BA 窗口冗余 → 平滑位姿），以 LOST 率为约束。
- **预期收益**：中段旋转漂移回落，RPE 给出可解释的改进曲线。
- **验证**：RPE 曲线前后对比；LOST 帧数不增加。

## 3. P2 — 架构与性能（长期）

### P2.1 单后台线程任务流水线（落地 THREADING_DESIGN）

- **现状**：设计文档已定稿，但代码仍为同步单线程；Local BA/回环/全局 BA 在主线程执行 → FPS 波动。
- **设计**：跟踪（主线程）→ 无锁队列 → 后台线程执行 Local BA/回环检测/位姿图/全局 BA；
  关键帧与地图点用细粒度互斥；轨迹/状态输出仍主线程（保证 Viewer 流畅）。
- **验证**：FPS 波动（P95/P5）与回环事件期间的帧耗时；单测保持确定性（后台线程默认关闭）。

### P2.2 地图规模控制

- **现状**：KITTI 00 全图 50 万点、3133 KF；`selectLocalWindow` 每次 O(KF×点) 扫描，长序列增长型变慢。
- **设计**：观测数动态 cull（低观测点提前剔除）；Local BA 窗口候选上限；回环后旧区点降采样。
- **验证**：地图点/KF 数-帧号曲线；单帧耗时-帧号曲线（无增长型劣化）。

### P2.3 跨子地图回环融合（SE3，双目绝对尺度）

- **现状**：跨 Atlas 子地图候选被显式拒绝（DBoW3 db 跨子地图缓存，但无跨尺度融合）。
- **设计**：双目子地图绝对尺度一致 → 跨子地图回环直接用 SE3 验证；
  位姿图顶点集合 = 各子地图 KF，边 = 子地图内里程计 + 跨子地图回环边，首子地图锚定，
  Atlas `origin_Twc` 对齐各子地图世界系。
- **验证**：双子地图合成回环单元测试；长时 LOST 后重定位回旧图场景。

## 4. 优先级与里程碑

| 优先级 | 事项 | 依赖 | 预期 ATE 收益 |
|--------|------|------|---------------|
| P0-1 | 全局/局部 BA 放开点自由度（双目全 BA） | 无 | 显著（中段残差收敛） |
| P0-2 | 回环检测提前（Top-20 + 位置先验 + 冷却改 KF 计数） | 无 | 显著（提前校正漂移） |
| P1-1 | ASan 定位非确定性崩溃 + 分带参数收敛 | 无 | 稳定性（流畅度硬伤） |
| P1-2 | RPE 指标 + 深度加权 + KF 阈值实验 | P1-1 之后 | 中等（旋转漂移抑制） |
| P2-1 | 单后台线程流水线 | P0 全部 | 性能/流畅度 |
| P2-2 | 地图规模控制 | P2-1 | 长序列稳定性 |
| P2-3 | 跨子地图回环融合 | P0-2 | 场景级（LOST 恢复） |

**实施顺序**：P0-1 → P0-2 → P1-1 → P1-2 → P2-1 → P2-2 → P2-3。
每项独立提交，均以"修复前 → 修复后 KITTI 00 ATE/RPE 对比 + 单测全过"作为验收门槛。

## 5. 风险与决策记录

- **全 BA 收敛性**：放开点自由度后若 Huber 阈值/信息权重不当可能发散 → 以观测数 ≥3 + 固定最早 2 帧
  为安全网；先在 Local BA 窗口（10 KF）验证再上全局。
- **检测提前的误检**：位置先验会引入假候选 → PnP 验证门槛（50 内点 / 0.85 比例）不可放松。
- **后台线程正确性**：与 Viewer 共享地图数据 → 线程化只移动"优化类"任务，地图读写在互斥下进行；
  提供 `VSLAM_SINGLE_THREAD` 编译开关一键回退。
- **ASan 与 -msse2**：ASan 构建需与 g2o ABI 对齐（沿用 -msse2 16 字节对齐），避免误报。
